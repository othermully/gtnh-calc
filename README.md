# GTNH Calculator

## Overview

This project aims to simplify calculations for the GregTech New Horizons modded minecraft pack.

This calculator only works for the Steam Age. As this project progresses (and my minecraft progression), i will add other tier calculators

## Features

- Calculate required # of boilers for desired Steam/s output
- Calculate water consumption for desired Steam/s ouput
- Calculate chunk distance in blocks
- Ability to select different types of boilers
